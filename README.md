SECOND HAND BOOK MARKET

Project Description:
This is a Linux Shell Scripting based project for managing second-hand books.

Features:
1. Add a new book.
2. Search books by ID or name.
3. Mark a book as sold.
4. Calculate seller earnings.
5. Display five cheapest available books.
6. View all books.
7. Create backup of book records.
8. Maintain activity logs.
9. Generate unsold books report.

Technologies Used:
- Ubuntu Linux
- Bash Shell Scripting
- CSV File Handling
- AWK, GREP, SORT and other Linux commands

Cron Job:
Schedule: Every Sunday at 7:00 PM
Cron Expression: 0 19 * * 0

Report Script:
generate_report.sh

Note:
Cron and crontab are not available in the current CoCalc environment. The schedule is documented but automatic execution is not configured.
